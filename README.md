# react-native-network-security

React Native security library that ensures the app communicates only through trusted, secure, and uncompromised network environments.

## Installation


```sh
npm install react-native-network-security
```


## Usage


```js
import { multiply } from 'react-native-network-security';

// ...

const result = multiply(3, 7);
```
